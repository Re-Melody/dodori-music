# 차량 연동 관점 재검증 — 2026-11-09 (KST)

## 판정

일반 Android 환경의 기능 QA를 통과한 프로토타입이다. Pleos/실차 탑재 검증 완료를 의미하지 않는다.
재현된 오류 3건과 공식 문서 대조에서 확인한 보완 2건을 수정했다.

## 실제 검증 환경

- Windows, JDK 21, Android SDK 34.
- Pixel_2, Android 14 / API 34 / Google APIs x86_64.
- 기본 화면: 1080×1920, 420 dpi.
- 연결 기기 및 설치 이미지 확인 결과 일반 Android 에뮬레이터만 사용 가능했다. AAOS/Pleos 시스템 이미지와 실차는 없다.
- APK의 `MediaBrowserService`, `MediaSession`, `MediaPlayer`, 실제 Android 오디오 포커스 중재를 사용했다.
- 위치 검사는 에뮬레이터 테스트 GPS 주입이다. 차량 GPS 수신 검사가 아니다.
- 호스트 오디오를 비활성화해 실행했다. 재생 상태·시간 진행은 검증했지만 스피커 청취 품질은 검사하지 않았다.

## 네트워크 단절 및 화면 확인

에뮬레이터 Wi-Fi와 모바일 데이터를 모두 끄고 `dumpsys connectivity`의
`Active default network: none`을 확인한 뒤 재검사했다.

- `media` 14개, `lifecycle` 6개, `permissions` 3개, `system-stop` 4개: **27개 모두 성공**.
- 단절 상태에서도 내장 음원 재생·자동 다음 곡·시스템 제어·화면 재생성·권한 거부 대체·정지가 동작했다.
- 테스트 후 Wi-Fi/모바일 데이터가 기존 값(각각 1)으로 복원된 것을 확인했다.
- 결과: `build/verification/vehicle-qa-offline/summary.txt`, `network.txt`, 묶음별 `.txt`.
- 최종 에뮬레이터 crash 버퍼에 기록이 없었다. ANR·장시간 안정성 검사까지 통과했다는 의미는 아니다.
- 컴퓨터 화면으로 초기 지도 타일·세로 배치·미니 플레이어·하단 메뉴를 확인했다.
  보관함 표시는 자동화된 기기 View 검사로 확인했다. 추가 화면 클릭은 사용자 입력과 겹쳐 실행되지 않았다.
- 최근 앱 목록에서 직접 제거하는 수동 재검사는 이번에 완료하지 못했다. 해당 종료 콜백 코드는 존재하지만,
  시스템 정지 검사와 실제 최근 앱 제거 검사를 구분한다.

## 실차/Pleos에서 남은 필수 검증

| 항목 | 현재 증거 | 필요한 다음 확인 |
|---|---|---|
| Pleos 위치 | 공식 SDK 1.1.3 연동 및 빌드, 전용 권한 흐름 보완 | SDK 사용 승인, 권한 승인/거부, 개인정보 위치 차단, 실제 콜백/오류/해제 |
| 차량 미디어 화면 | 일반 Android 브라우저/컨트롤러 통과 | Pleos 미디어 센터 통합, 앱 라이브러리 실제 노출, 핸들/Media 버튼/Tune Knob 동작 |
| Gleo 음성 | 표준 검색 재생 콜백만 검사 | 차량 음성 인식→앱 검색 연결. 현재 Gleo 연동 완료로 판단하지 않음 |
| 주행 제한 | CarUxRestrictions 연결 및 상태 불명 시 조작 제한 코드 | 정차→주행→정차와 연결 해제, 목록/지도/보관함 제한, 실제 시스템 Activity 차단 |
| 오디오 | 일반 Android 포커스 경쟁 시 동작 통과 | 통화/내비/안전 안내 우선순위, 차량 음량 그룹/출력, duck 적용·해제 청취 |
| 전원 | Activity 재생성·백그라운드 검사 | 차량 suspend/resume, 시동/프로필 변경, 재부팅 시 의도치 않은 재생 여부 |
| 차량 화면 | 현재 세로 고정 UI | 가로/와이드 차량 화면에서 잘림·조작성. 세로 고정은 해결하지 않았음 |
| 배포 | debug APK 생성 | 실제 음원 권리/공급, 전국 데이터, 서명 release, 차량 심사 |

휴대폰 에뮬레이터의 화면 재생성이나 백그라운드 테스트를 차량 suspend/resume 검증으로 대체하지 않는다.
Pleos 미디어 센터 템플릿은 현재 의존성/통합 코드에 포함돼 있지 않다. MBS 구현만으로 라이브러리·물리 버튼 노출을 보장하지 않는다.

## 재실행

폐기 가능한 일반 Android 에뮬레이터 **1개**에서만 실행한다. 테스트는 즐겨찾기·재생 상태·위치 권한을 변경한다.
`--offline`은 해당 에뮬레이터의 Wi-Fi/모바일 데이터를 잠시 끄고 원래 값으로 복구한다.

```powershell
.\gradlew.bat :app:assembleStandardDebug :app:assemblePleosDebug :app:assembleStandardDebugAndroidTest :app:testStandardDebugUnitTest :app:lintStandardDebug :app:lintPleosDebug
adb install -r app/build/outputs/apk/standard/debug/app-standard-debug.apk
adb install -r app/build/outputs/apk/androidTest/standard/debug/app-standard-debug-androidTest.apk
python tools/vehicle_qa.py --adb PATH_TO_ADB
python tools/vehicle_qa.py --adb PATH_TO_ADB --offline --label vehicle-qa-offline --suites media lifecycle permissions system-stop
```
