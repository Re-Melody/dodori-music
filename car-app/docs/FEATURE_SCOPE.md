# 1차 기능 범위

## 구현 대상

위치 기반 음악 지역, 지역별 추천과 이유, 재생 기본 조작, 이동 시 추천 갱신,
음악 지도, 시연 경로를 중심으로 구성했습니다.
장르와 즐겨찾기는 로컬 기능으로 포함했습니다.

WayVibe APK 추출물은 완전한 Flutter 원본 프로젝트가 아닙니다.
현재 기능은 추출물 전체를 이식하거나 서버 알고리즘을 복원한 결과가 아닙니다.
RoadyGoat의 외부 추천 서버와 서비스 키는 자동 연결하지 않습니다.
지역-곡 매핑은 명시적인 시연 카탈로그이며 추천 이유도 그 범위에 맞춰 표시합니다.

## 이번 범위에서 제외

- 휴대폰 앱, iOS·CarPlay·Android Auto 투사 연동
- 계정·클라우드 동기화·결제·소셜 로그인
- Spotify·Apple Music 상용 재생과 계정 인증
- 내비게이션·전국 지오코딩·교통 경로
- 날씨·역사 이야기·지질·생태계 시각 효과
- 독립 음성 인식·Gleo 전용 function schema

시스템 표준 검색 재생 명령은 구현했으나 Gleo 실서비스 음성 연동 검증을 뜻하지 않습니다.

## 데이터 확장

`Catalog.regions`와 `Catalog.tracks`의 연결을 실제 서비스 데이터로 교체할 수 있습니다.
현재 반경 원 기반 지역 판별은 시연용이며 행정구역 경계와 같지 않습니다.
지역 판별에는 1km 경계 여유를 두어 좌표 흔들림으로 추천이 반복 전환되는 것을 줄입니다.
등록 지역 밖에서는 다음 추천을 비우되 이미 재생 중인 곡은 유지합니다.
